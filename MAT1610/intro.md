# Bienvenidos a los Laboratorios de Cálculo I (MAT1610)

Esta colección de 11 laboratorios interactivos ha sido diseñada para complementar el curso de **Cálculo I**, utilizando el texto de **James Stewart** como guía fundamental. 

## Objetivos del Laboratorio
El propósito de estos laboratorios es que logres "descubrir el Cálculo" a través de la experimentación computacional [7]. Aquí podrás:
* **Visualizar conceptos abstractos**: Mediante gráficas dinámicas y widgets interactivos [8, 9].
* **Realizar cálculos simbólicos**: Usando la librería **SymPy** para obtener resultados exactos [2, 10].
* **Analizar datos reales**: Aplicando modelos matemáticos a fenómenos del mundo real [11, 12].

## Estructura de cada Sesión
Siguiendo una metodología de aprendizaje activo, cada notebook está organizado de la siguiente manera [13, 14]:
1. **Introducción Teórica**: Repaso conceptual breve.
2. **Ejemplos Guiados**: Código paso a paso para aprender las herramientas de Python.
3. **Ejercicios Propuestos**: Retos para que pongas a prueba lo aprendido.
4. **JNB LAB**: Un proyecto aplicado o una exploración visual profunda.

## ¿Cómo usar este libro?
Puedes navegar por los capítulos en la barra lateral izquierda. Para interactuar con el código, busca el botón de **"Launch"** (el ícono del cohete) en la parte superior de cada página para abrir el laboratorio en la nube (vía Binder o Google Colab) [15, 16].

¡Esperamos que estos laboratorios te ayuden a ver la belleza y utilidad intrínseca de esta materia! [17]
